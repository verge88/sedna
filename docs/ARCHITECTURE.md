# Архитектура SEDNA

## Поток данных

`Compose → SednaViewModel → WordDatabase (SQLite) / StudyPreferences (SharedPreferences)`.

Пользовательский поиск: `Compose → SednaViewModel → DictionaryGateway → Free Dictionary API + Datamuse`. HTTP выполняется через `Dispatchers.IO`, соединения имеют таймауты 8 секунд. После успешного ответа статья кешируется в памяти до закрытия процесса. В карточку SQLite попадут только слова, которые пользователь явно сохранил.

Каталог TSV из `assets` — независимый от API офлайн-источник русских переводов. Тематические наборы импортируются в словарь через `INSERT OR IGNORE` с уникальным `term COLLATE NOCASE`.

## SRS

Новые слова имеют `dueAt = 0` и сразу доступны для тренировки. После оценки `Scheduler.review` изменяет:

- `AGAIN` — через 10 минут, число успешных повторений сбрасывается;
- `HARD` — минимум через 1 день, коэффициент лёгкости немного уменьшается;
- `GOOD` — 1 день, 3 дня, затем предыдущий интервал × коэффициент;
- `EASY` — 4 дня для новой карточки, далее увеличенный интервал.

Коэффициент ограничен 1.3–3.2. История `attempts/correct/lapses/lastReviewedAt` сохраняется вместе с карточкой. Транзакция SQLite защищает обновление оценки. Статистика серии дней хранится локально отдельно от карточек.

## Доступность и безопасность

- Material 3 предоставляет семантику элементов управления, контраст в светлой/тёмной теме.
- В сеть отправляется только введённый поисковый запрос. Нет аналитики, учётных записей или рекламы.
- Только `android.permission.INTERNET`.
- Данные можно экспортировать/импортировать через системный Android Storage Access Framework.
- Доступ к сети может быть ограничен провайдером; приложение сохраняет офлайн-функции.
- При будущих изменениях схемы SQLite надо создавать явные миграции, а не удалять пользовательский словарь.

## Дальнейшее развитие

Рекомендуемые следующие итерации: расширение учебных наборов, контекстные упражнения и задания на слух, возможность офлайн-автоперевода из свободных словарей, уведомления о повторениях, end-to-end UI tests, отдельная база для истории событий и синхронизация по выбору пользователя.
