# SEDNA · English Vocabulary

**SEDNA** — нативное Android-приложение на **Kotlin + Jetpack Compose** для системного расширения английского словарного запаса. Вдохновлено идеей коротких языковых занятий, но не использует дизайн или материалы Busuu. Интерфейс монохромный, на русском языке.

## Что реализовано

- **Главная:** статистика, ежедневная цель и серия занятий.
- **Учебные подборки:** 144 слова, 12 тем, уровни A1–B2; все наборы доступны **офлайн**.
- **Онлайн-поиск:** словарные определения, примеры, транскрипция; отдельные подсказки поиска.
- **Личный словарь:** добавление, поиск, фильтры, изменение перевода, удаление.
- **Тренировка:** карточки с самостоятельной оценкой, ввод английского слова, тест с вариантами.
- **Интервальные повторения:** адаптивный алгоритм в духе SM-2, 4 оценки ответа и очередь по датам.
- **Произношение:** системный Android Text-to-Speech (en-US).
- **Прогресс:** уровни, точность, количество ответов, streak, дневная цель.
- **Настройки:** светлая и тёмная чёрно-белые темы.
- **Данные:** локальная SQLite, JSON-экспорт и импорт слов. Нет регистрации и собственного сервера.

## Технологии

Kotlin 2.3.20, Android Gradle Plugin 8.13.2, Gradle 8.13, Jetpack Compose BOM 2026.09.00, Material 3, Android ViewModel, coroutines, SQLiteOpenHelper, platform TTS. **minSdk 26, compileSdk 36, targetSdk 35.**

## Собрать и запустить

1. Откройте корневой каталог проекта в Android Studio (JDK 17, установлен Android SDK 36), дождитесь Gradle Sync.
2. Запустите конфигурацию **app** на устройстве/эмуляторе Android 8+.
3. Или выполните `./gradlew :app:assembleDebug` (на Windows — `gradlew.bat :app:assembleDebug`).
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Первый запуск `gradlew` скачивает официальный Gradle wrapper JAR версии 8.13 из репозитория Gradle; в Linux/macOS он сверяется с Git blob SHA. Сам Gradle загружается из `services.gradle.org`. В GitHub Actions используется `gradle/actions/setup-gradle`, поэтому JAR в репозитории не нужен.

Проверить алгоритм повторений: `./gradlew :app:testDebugUnitTest`. Workflow **Android CI** проверяет сборку и тесты при push/PR, сохраняет debug APK в GitHub Actions → Artifacts.

## Открытые словарные API: условия

| Источник | Что загружается | Доступ |
| --- | --- | --- |
| [Free Dictionary API](https://dictionaryapi.dev/) | Определения, транскрипции и примеры EN | Бесплатно, без ключа; бесперебойность и отсутствие ограничений не гарантированы |
| [Datamuse](https://www.datamuse.com/api/) | Подсказки похожих слов | До 100 000 запросов/день без ключа **до 1 февраля 2027**; затем нужен API-ключ |

**Важно:** публичного бесплатного API с гарантированно безлимитными запросами нет. Приложение не обещает «безлимитный» сетевой доступ: запросы выполняются только по действию пользователя, успешные ответы кешируются в памяти, сохранённые слова доступны офлайн. После 1 февраля 2027 подсказки Datamuse потребуют доработки для API-ключа либо замены провайдера; словарь и повторения продолжат работать.

API definitions возвращаются на английском. Для 144 стартовых слов переводы на русский уже включены. Для нового найденного слова **пользователь вводит русский перевод**, после чего карточка готова к тренировкам. Автоматический машинный перевод не обещается.

## Структура

```
app/src/main/
  assets/starter_words.tsv          # 144 слова по темам
  java/com/sedna/words/
    MainActivity.kt                 # точка входа
    SednaViewModel.kt               # UI state, use cases и экспорт
    data/Word.kt                    # карточка, оценка, SRS
    data/WordDatabase.kt            # SQLite
    data/StudyPreferences.kt        # цель, streak, тема
    data/SeedCatalog.kt             # офлайн-наборы
    data/DictionaryGateway.kt       # Free Dictionary + Datamuse
    ui/                             # экраны и ч/б тема
app/src/test/                        # JUnit-тесты SRS
.github/workflows/android.yml       # CI сборка APK
```

## Ограничения первой версии

Это функциональная локальная версия без аккаунтов, синхронизации между устройствами, push-уведомлений, видеокурсов и автоматического RU-перевода новых слов. Для публикации в Google Play потребуется отдельно протестировать приложение на реальных устройствах, настроить подпись release-сборки и проверить лицензии внешнего словарного контента.
